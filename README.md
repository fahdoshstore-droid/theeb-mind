# 🐺 ذيب مايند — Theeb Mind

**مدقّق قرارات التداول بالذكاء الاصطناعي** — منصة عربية بالكامل (RTL) تحاسبك على جودة قرارك *قبل* أن تحاسبك السوق على نتيجته.

> **Theeb Mind** — an Arabic-first AI trading-decision audit platform. It scores the *quality* of every trading decision before the market scores its outcome.

🔗 **تجربة مباشرة / Live demo:** https://theeb-mind-audit.replit.app

---

## الفكرة

المتداول لا يخسر بسبب صفقة واحدة، بل بسبب *نمط قرارات* رديء يتكرر دون أن يلاحظه. ذيب مايند يسجّل كل قرار، يقيّمه لحظياً، يكشف الأنماط المتكررة من ذاكرته، ويقدّم تدقيقاً نفسياً وسلوكياً كاملاً — مثل مدقّق حسابات، لكن لقراراتك.

## أبرز الميزات

| الميزة | الوصف |
|---|---|
| 🎯 **تحليل الشارت وتقييم الجودة** | تقييم فوري لكل قرار (درجة + تصنيف) بناء على التحليل الفني وإدارة المخاطر والانضباط |
| 🧠 **محرك الذاكرة** | بصمة لكل نمط تداول؛ يتعرّف على الأنماط المتكررة ويحذّرك من أخطائك القديمة قبل تكرارها |
| 📊 **ذكاء السوق بأسعار حية** | أسعار مباشرة (بيتكوين، إيثيريوم، الذهب، يورو/دولار) من مصادر مجانية بدون مفاتيح API، مع تبديل تلقائي بين المصادر عند انقطاع أحدها |
| 🧾 **سجل التداول والمحاسبة** | يومية كاملة لكل قرار ونتيجته، مع ربط النتائج بجودة القرار وقت اتخاذه |
| 🧘 **التدقيق النفسي** | رصد حالات الانتقام والثقة الزائدة والتردد، وربطها بأداء القرارات |
| ⛔ **حُرّاس الانضباط** | مناطق القتل (Killzones)، أيام الحظر، وفترات تعتيم الأخبار — المنصة توقفك قبل القرار المتهور |

## البنية التقنية

- **Monorepo:** pnpm workspaces + TypeScript
- **الواجهة:** React + Vite — تصميم داكن عربي RTL بالكامل (`artifacts/theeb-mind`)
- **الخادم:** Express + better-sqlite3 (`artifacts/api-server`)
- **الأسعار الحية:** Binance → CoinGecko (تبديل تلقائي) + البنك المركزي الأوروبي للعملات — بدون أي مفاتيح API
- **عرض تقديمي:** عرض الهاكاثون ضمن المشروع (`artifacts/theeb-mind-pitch`)

## التشغيل محلياً

```bash
pnpm install

# الخادم (منفذ 8080)
pnpm --filter @workspace/api-server run dev

# الواجهة
pnpm --filter @workspace/theeb-mind run dev
```

الطلبات إلى `/api/*` تتطلب ترويسة `X-Api-Key` (مفتاح تجريبي للنسخة الحالية: `user-1_devkey`).

## هيكل المشروع

```
artifacts/
├── theeb-dashboard/   # THEEB MIND — Decision Dashboard لـ NQ/MNQ (LONG / SHORT / NO TRADE)
├── theeb-mind/        # واجهة المنصة (React + Vite، عربي RTL)
├── api-server/        # خادم REST (Express + SQLite)
└── theeb-mind-pitch/  # شرائح العرض للهاكاثون
```
